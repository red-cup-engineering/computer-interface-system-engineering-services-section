---
title: "Task Mode"
date: 2026-06-17
---


This cycle made Vibemacs task files feel more like native Emacs workspaces.
The project has been building persisted Markdown task files into the durable center of agentic work: they can hold acceptance checks, checkpoints, decisions, verification evidence, and task-specific handoffs.
Until now, though, their commands still lived mostly behind the global `C-c v` prefix.

Persisted task files under `dev/tasks/` now enable `vibemacs-agent-task-mode`.
The mode adds local keys for the task workflow: jump to the next unchecked checkbox, toggle a checkbox, insert verification evidence, insert a checkpoint, record a decision, and copy a task handoff.

This keeps task work closer to the buffer where the task lives.
A programmer can open a task file and immediately use task-local commands without mentally switching back to the project-wide cockpit.

The implementation stays small and Emacs-native: a buffer-local minor mode, a task-file detector, and a `find-file-hook` that turns the mode on only for persisted Vibemacs task files.
